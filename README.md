# Welcome to the **Oracle Database@Azure Data & AI Hackathon**!  
In this hackathon, you’ll complete guided missions that prepare you to build **AI‑powered, agentic applications** using **Oracle Database running inside Microsoft Azure**, combined with **Microsoft Fabric** and **Azure AI services**.

You’ll learn how to:
- Run enterprise workloads on Oracle Database@Azure
- Mirror Oracle data into Microsoft Fabric for analytics and AI
- Enable natural‑language insights over Oracle data
- Build Retrieval‑Augmented Generation (RAG) pipelines
- Deliver a full **agentic AI solution** using Microsoft Foundry

Complete all missions and add your **own creative twist** to win exciting prizes.

## 🧭 Mission Overview

Each mission builds on the previous one, taking you from foundational setup to a complete **Oracle Database@Azure–powered agentic AI application**.

---

### **Mission 1: Provision Oracle Database@Azure & Run Workloads**

**Objective:** Establish Oracle Database@Azure as the system of record for AI workloads.

You will:
- Provision Oracle Database@Azure
- Bring your own structured data
- Validate connectivity, security, and performance
- Run baseline workloads in Azure‑hosted Oracle Database

✅ **Outcome:** A production‑ready Oracle database running inside Azure datacenters, ready for AI scenarios.

---

### **Mission 2: Mirror Oracle Data into Microsoft Fabric**

**Objective:** Enable analytics and AI workflows by synchronizing Oracle data into Fabric.

You will:
- Configure data mirroring from Oracle Database@Azure into Microsoft Fabric
- Keep datasets synchronized for downstream analytics
- Prepare data for AI consumption in Fabric

✅ **Outcome:** Oracle data available in Microsoft Fabric for unified analytics and AI workflows.

---

### **Mission 3: Enable Data Agents for Natural Language SQL Insights**

**Objective:** Democratize data access using natural language.

You will:
- Enable data agents over mirrored Fabric datasets
- Ask natural‑language questions and generate SQL automatically
- Validate insight generation without writing SQL manually

✅ **Outcome:** Natural‑language–driven insights over Oracle data, lowering the barrier to data exploration.

---

### **Mission 4: Build RAG Pipelines (Oracle + Azure AI Search)**

**Objective:** Ground AI responses in trusted enterprise SQL data.

You will:
- Generate and store embeddings from Oracle data
- Implement semantic and hybrid search
- Build Retrieval‑Augmented Generation (RAG) pipelines
- Use Azure AI Search for vector and semantic retrieval

✅ **Outcome:** AI responses grounded in Oracle SQL data using enterprise‑grade RAG patterns.

---
### **Mission 5: Build Custom Copilots in Microsoft Copilot Studio**

**Objective**:
Democratize access to enterprise data by enabling users to interact with Oracle‑backed insights using natural language through custom copilots built in Microsoft Copilot Studio.
✅ **Mission Outcome**:
By the end of this mission, you will have built and deployed a custom Copilot that allows business users to ask questions in natural language and receive grounded, trustworthy answers powered by Oracle Database @ Azure and Microsoft’s AI platform.

What You’ll Build:

- A custom Copilot created using natural language and visual authoring in Microsoft Copilot Studio
- Natural‑language experiences that translate user questions into data‑backed insights
- A Copilot grounded in enterprise data sources (Oracle Database @ Azure and/or mirrored data in Microsoft Fabric)
- Secure, governed access to AI‑generated responses suitable for enterprise use

---
### **Mission 6: Build an Agentic Solution in Microsoft Foundry**

**Objective:** Deliver a complete, production‑ready AI application.

You will:
- Build an agentic solution using Microsoft Foundry
- Orchestrate tools, RAG pipelines, and SQL queries
- Expose functionality via APIs
- Demonstrate automation, reasoning, and decision support

✅ **Outcome:** A cohesive agentic AI application combining:
- Oracle Database@Azure  
- Microsoft Fabric  
- Azure AI Search  
- Microsoft Foundry
